# README previews

The animated previews are separate captures, each placed beside the feature it
demonstrates in the [main README](../../README.md). They loop automatically.

| File | Dimensions | Duration | Size | Content |
| --- | --- | --- | --- | --- |
| `campus-traffic.webp` | 1280 × 760 | 12.1 s | 2.04 MiB | Actual Office campus and moving traffic |
| `extalia-deligating-teams.webp` | 800 × 520 | 24.6 s | 4.59 MiB | Existing team-delegation preview, retained unchanged |
| `observe-session.webp` | 1280 × 900 | 16.0 s | 0.66 MiB | Working sample projects across Codex, Antigravity and Claude Code |
| `knowledge-graph.webp` | 1120 × 744 | 13.6 s | 2.17 MiB | 1,600 notes / 4,427 links, canvas selection, note detail and node dragging |
| `skills-grimoire.webp` | 1120 × 946 | 18.3 s | 2.09 MiB | Shelf pagination, book hovers, opening and swipe page turns |

The four new previews were recorded on 2026-11-13 from the real OfficeCanvas,
ObserverPage, Knowledge views and SkillLibraryView in isolated browser harnesses.
Observe events, projects, notes and skill content are synthetic demonstration
data. The Grimoire catalog illustrates 42 sample books; it is not an inventory
of shipped built-in skills. No user profile, transcript, credentials or external
application configuration was used. Campus traffic uses the scene's actual
vehicle simulation; the other views use their real interaction handlers.

The captures were encoded as animated WebP with image dimensions and loop/frame
metadata checked, without EXIF or XMP metadata. New media totals about 7.0 MiB.
The existing delegation WebP was not re-encoded. These demonstrations document
the UI; they are not live-provider, scanner, graph-performance or release-gate
certification. Application code and scene assets retain the terms described in
the main README and asset inventory.
