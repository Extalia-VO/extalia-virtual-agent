# Extalia v0.4.352 — release candidate

Status: source candidate prepared; GitHub CI, main integration, release artifacts
and npm publication remain separate gates. This page does not announce an
available installer or registry version.

This candidate gathers v0.4.335–v0.4.352 after the published v0.4.334 baseline.

## Changes

- **Schedules:** suggested tasks, a simple editor, existing or new conversations,
  advanced cron/interval/team settings and creation from ordinary Native prompts.
  Missed eligible jobs catch up once after host downtime or sleep. Verified
  endpoint and first-request upstream outages retain one occurrence with
  persisted, capped-rate retries and the same session/pending prompt. Output,
  tools, steering, changed history/access or uncertain persistence prevent replay.
- **Knowledge:** source-grounded project updates, clearer learning notices and
  live resource inspection, plus a softer graph appearance with readable titles.
- **Skills:** generated candidate metadata, categories and bounded evaluation
  evidence support review; revision-bound checks and explicit activation remain
  required. No additional scanner platform is certified by this candidate.
- **Chat and Observe:** activity/resource inspection and scoped notification
  placement retain source identity and permission boundaries.

The v0.4.352 correction compiles Unix-only project-Knowledge inventory helpers
only on supported targets, preserving strict Windows Clippy checks and the
existing unsupported-platform refusal.

## Verification

The v0.4.351 source baseline passed local `VITEST_MAX_WORKERS=2 pnpm check`: 836 TypeScript suites / 11,632
tests, four suites / 29 existing skips, 751 Rust tests and Web/CLI/Desktop builds.
The upstream retry suite includes 12 temporary-host cases and a real loopback
HTTP test that stops and restores the upstream listener. The workspace-admission
regression reproduces a duplicate provider request under the old guard and
passes with the fix.

The Unix-only correction passes ten focused project-Knowledge tests, strict
workspace Clippy and formatting locally. Cross-platform CI, release packaging and registry integrity/install checks must
be recorded before publication. Controlled fixtures do not certify every model
provider, operating-system power-loss behavior or remote computation/billing.

## Installation after publication

```bash
npm install -g extalia-vo@latest
extalia
```

Confirm the installed version with `extalia version`; restart a running Bridge
after updating. The application package installs its matching platform daemon.
See [Schedules](../getting-started/schedules.md), [packaging](packaging.md) and
[version policy](versioning.md) for operation and platform limits.
