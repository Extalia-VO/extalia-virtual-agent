# Extalia v0.4.226 — Desktop and npm/Web preview

This release gathers the v0.4.172–v0.4.226 updates. It remains a v0.4 preview;
it does not complete the v0.5 scanner, Python worker, or effect-time authority
gates.

## Highlights

- **Observed Codex conversations:** Observe and Office can send messages through
  the original native conversation, and can answer supported newly received
  requests through Codex's existing public interfaces. Permission-hook setup is
  explicitly reviewed and remains subject to user-controlled trust and modes.
  Extalia does not start another Codex session or silently grant permissions.
- **Conversation tools:** paired tools can return answers to the existing source
  conversation through expiring, one-use reply channels. Unsupported or late
  requests remain with the source app. The repeated composer hint is removed,
  and structured user replies display their answers instead of raw payload text.
  The compact prompt places its send icon beside the input.
- **Missions and teams:** project review, Native session setup, exact mission
  cancellation, bounded Native teams, and Hermes profile-aware team limits are
  available with explicit runtime and connection boundaries. Failed or uncertain
  operations retain their status instead of being silently retried.
- **Knowledge and skills:** the Knowledge graph includes filtered 2D/3D
  exploration, while Grimoire provides searchable books and paged skill
  registry browsing. These are browsing and routing aids; they do not grant
  vault-wide access, activate skills, or replace scanner and consent checks.
- **Native controls:** workspace folder boundaries, bounded memory/context
  controls, task/status evidence, and safer recovery records improve visibility
  and admission checks. Recorded preparation or cancellation is not proof that
  external processes or writes have settled; complete effect-time authority and
  recovery closure remain future work.
- **Office and setup:** the Office adds a responsive 24-seat team workspace,
  improved character navigation and automatic camera behavior. Installers offer
  guided macOS and Windows setup and an offline per-user Linux setup.

## Install or update

Install the CLI package, which includes the Web client, local Bridge, and the
matching platform daemon:

```bash
npm install -g extalia-vo@latest
extalia
```

Requires Node.js 22.13+ on the 22.x line, or 23.4+ on newer lines. Do not install
inside a pnpm-linked checkout. Desktop installers target macOS Apple Silicon
and Intel, Windows x64, and Linux x64. The Web ZIP needs a local Bridge or
Desktop host for agent execution.

macOS preview builds are ad-hoc signed, not notarized, and may show Apple's
unidentified-developer warning. They use manual downloads for updates. Linux
AppImage runtime dependencies still apply. Consult `SHA256SUMS.txt` in a
published release to verify downloaded files.

## Scope and limitations

- Observed Codex controls require a supported existing native connection and
  operate on that original conversation. Extalia does not create a source
  session or permission grant. Hook trust, permission modes, and real Desktop
  activation remain user-controlled; some permission tools may still require
  Codex itself. Unsupported endpoints and late requests remain in the source
  application.
- v0.5 production scanner evidence, embedded Python distribution and
  supervision, complete effect-time authority, and full workspace/agent ACLs
  are not declared complete. A successful build or smoke check does not close
  those product gates.
- Public scene assets retain their individual notices and restrictions. This
  release note makes no broader license verification or redistribution claim.
