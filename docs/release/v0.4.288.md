# Extalia v0.4.288 — Desktop and npm/Web preview

**Release preparation: artifact validation and publication are pending.** During
this preparation, npm `latest` remains v0.4.227. Planned filenames below do not
mean those downloads are available. Check the
[release page](https://github.com/Extalia-VO/extalia-virtual-agent/releases)

This update gathers v0.4.228–v0.4.288 since the previous v0.4.227 release. It
remains a v0.4 preview; it does not declare the v0.5 acceptance gates complete.

## Changes since v0.4.227

- **Reviewed work continuity:** change a Native model connection while retaining
  the same session and history, or hand reviewed working notes and retained
  source evidence to an existing agent conversation. Verified routes and manual
  packets have distinct delivery receipts. Scoped archive access, explicit
  observed project association and reviewed Native workspace moves preserve
  source identity, privacy and destination access boundaries.
- **Observed messaging:** a shared composer supports queued messages,
  attachments and capability-specific controls across Chat, Observe and the
  Office. Native attachments, source queues and paired cooperative inboxes use
  their actual supported routes. Unknown delivery remains uncertain and is not
  silently resent or rerouted; hooks and transcripts alone do not grant control.
- **Skills and Grimoire:** browse live public marketplace results, inspect
  immutable package previews and import exact pinned bytes through security
  review. Revision provenance, permissions and source evidence remain visible.
  Imports never approve or activate a candidate. Supported macOS 14+ ARM64
  artifacts pair pinned SkillSpector 2.13.4 and bundled Python with their daemon;
  their final v0.4.288 release validation is still pending.
- **Deferred Native learning:** workspace vault policies can schedule bounded
  post-task curation and saved-team knowledge reviews. Run now/Snooze controls
  show the quiet countdown; foreground work takes priority. Confirmed notes and
  skill candidates have separate receipts, and candidates still require review
  and activation. The learning/artifact backend supports macOS and Linux;
  automatic curation and note/skill staging remain unavailable on Windows.
- **Office and application recovery:** checked furnished routes, chair and
  fitness contacts, door queues and lift waiting behavior improve movement.
  Camera attention has explicit Follow/Stop controls. Adaptive render budgets,
  hidden-avatar work reduction, cloned-resource cleanup and graphics recovery
  preserve drafts and attachments through scene restarts. Secondary pages load
  on demand, and the Web client reconnects after a Bridge restart.
- **Cross-platform verification fixes:** destination folder assertions now
  compare structured results across Windows and Unix path encodings. Inbox
  revocation tests wait for actual request admission, and strict Windows Clippy
  validation retains marketplace linked-file rejection.

## Install or update

The npm application package installs the local Bridge, Web client and matching
platform daemon together:

```bash
npm install -g extalia-vo@latest
extalia
```

Requires Node.js 22.13+ on the 22.x line, or 23.4+ on newer lines. Keep the global
install outside a pnpm-linked checkout. Until v0.4.288 is published to npm,
`@latest` installs the existing published version. A running Bridge must restart
after an update. The static Web ZIP needs a local Bridge or Desktop host to run
agents; the internal `@extalia/daemon-*` packages are not standalone applications.

## Scope and limitations

- Scanner execution is unavailable on Intel macOS, Windows and Linux pending
  verified native isolation. Missing, incomplete or malicious inspections leave
  candidates unavailable. Eligible instruction-only packages need separate
  digest-bound approval and activation; code/tool packages retain evaluation
  requirements. A bundled scanner is not completion of general Python workers,
  complete effect-time authority or full workspace/agent ACLs.
- Existing native conversations require supported, verified controls or explicit
  cooperative pairing. Manual-ready, queued and submitted receipts do not prove
  a model read the packet, completed work or settled an external operation.
  Real-provider certification, long-duration soaks and hardware FPS/memory
  acceptance remain separate from CI, builds and controlled fixtures.
- The opt-in CoreStore upgrades through schema 14 with its pre-migration backup.
  Older binaries refuse newer schemas; keep a profile backup before downgrading.
- Application source is MIT. Bundled scene assets keep their individual licenses,
  including non-commercial vehicles; the runtime commercial-assets switch does
  not remove those files. Read the [asset notices](../../apps/web/public-assets/THIRD_PARTY_NOTICES.md)
  before reuse or commercial distribution.
