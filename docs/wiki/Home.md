# Welcome to the Extalia Wiki

Extalia is an open-source **spatial AI-agent workspace and orchestration platform**. Its signature interface is a living 3D virtual office where AI agents and subagents are represented as workers, rooms represent functional systems, and real-time agent execution is rendered interactively.

---

## Key Highlights

- **Spatial Agent Observability:** AI agents and subagents operate within a contextual 3D office, visualizing execution states (idle, working, delegating, thinking) in real-time.
- **Provider & Runtime Agnostic:** Decoupled from any single model provider or runtime engine. Works with Hermes, Codex, Claude Code, Gemini/Antigravity, and custom engines via adapters.
- **Unified Workspace & Session Hub:** Connect workspaces to project repositories, maintain persistent execution history, and inspect sessions across multiple views: Office, Chat, Console, Tasks, Terminal, Files, Git, and Logs.
- **Historical Session Importer:** Seamlessly ingest and organize historical sessions from major agent environments without vendor lock-in or credential leakage.
- **Zero Lock-In & Local-First:** Strict data separation. User credentials, logs, and private histories remain strictly local. Exportable open session formats.
